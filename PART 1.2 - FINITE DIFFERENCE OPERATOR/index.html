Directional intensity changes become an edge map. A single threshold trades fine detail against unwanted texture.

01 / From intensity to gradients

The 512 × 512 grayscale image is converted from uint8 to float64 in [0, 1]. No resizing, smoothing, denoising, sharpening or histogram adjustment is applied. The finite difference filters are convolved directly with the input using SciPy, as permitted in Part 1.2.

Ix = I * [1, −1]   ·   Iy = I * [1, −1]T
M = √(Ix² + Iy²)

In the interior, Ix[y,x] = I[y,x] − I[y,x−1], while Iy[y,x] = I[y,x] − I[y−1,x]. A vertical boundary changes intensity across x, so it appears in Ix; a horizontal boundary changes intensity across y, so it appears in Iy. The magnitude combines both directions without depending on the sign of the change.

The two signed derivative displays share a scale of ±0.741176, with zero shown as middle gray. The magnitude is shown on a fixed [0, 1] display scale; raw values are preserved separately. Binarization uses raw magnitudes, not a contrast-normalized PNG.

02 / Choosing the edge threshold

Edge[y,x] = M[y,x] > 0.20

I selected T = 0.20 on intensities normalized to [0, 1]. At T = 0.05 and 0.10, the grass fills much of the lower-right region with dense texture responses. T = 0.15 reduces those responses but still leaves many scattered pixels. T = 0.20 removes substantially more grass texture while keeping much of the photographer's shoulder and arm outline, camera structure, and tripod legs. Raising the threshold to 0.25 or 0.30 removes more clutter but breaks up the head, camera and tripod contours further. The selected result is a compromise: grass responses remain, and weak clothing, hair and background edges are lost. Thresholding alone cannot preserve every real edge while rejecting all texture; no smoothing or post-processing is used to conceal that limitation.

This is a qualitative choice for this image, not a universally optimal threshold.

03 / Method, boundaries and verification

The convolution uses mode='same' and boundary='symm', so image size is preserved and boundary intensities are extended symmetrically. For these two-sample kernels, the leftmost x derivative and topmost y derivative are zero. Unlike the zero fill demonstrated in Part 1.1, this avoids a false outer contour against an assumed black background.

DX = np.array([[1., -1.]])
DY = DX.T

def gradients(image):
    """Return signed x/y backward differences and Euclidean magnitude.

    Symmetric boundary extension avoids a spurious edge against zero.
    Convolution flips the kernel: interior dx[y,x] = I[y,x] - I[y,x-1].
    """
    image = np.asarray(image, dtype=np.float64)
    if image.ndim != 2 or not image.size or not np.isfinite(image).all():
        raise ValueError('Expected a nonempty, finite 2D grayscale array.')
    dx = convolve2d(image, DX, mode='same', boundary='symm')
    dy = convolve2d(image, DY, mode='same', boundary='symm')
    magnitude = np.sqrt(dx ** 2 + dy ** 2)
    return dx, dy, magnitude


def threshold_edges(magnitude, threshold):
    """An edge is a raw gradient magnitude strictly greater than threshold."""
    magnitude = np.asarray(magnitude, dtype=np.float64)
    if magnitude.ndim != 2 or not magnitude.size or not np.isfinite(magnitude).all() or (magnitude < 0).any():
        raise ValueError('Expected a nonempty, finite, nonnegative magnitude array.')
    if not np.isfinite(threshold) or threshold < 0:
        raise ValueError('Threshold must be finite and nonnegative.')
    return magnitude > threshold

Six real-array unit tests verify horizontal and vertical direction, signed subtraction from uint8 input, constant-image boundaries, a 3–4–5 gradient magnitude, strict threshold comparison, and rejection of invalid inputs. The experiment also verifies that saved edge masks match direct thresholding of the saved floating-point magnitudes.

What I learned

Finite differences measure intensity changes, so they respond to texture as well as object boundaries. Combining both directions captures more contour orientations, but a magnitude threshold alone cannot distinguish texture from meaningful edges. Smoothing before differentiation is the next step to investigate in Part 1.3.
