I split an image into layers of fine detail and broad shapes. Every layer keeps the same size. I then combine apple and orange layers to make an oraple.

The supplied images

Both course images are 740 × 530 pixels. I convert them to float64 values from 0 to 1 without resizing or aligning them. The original grain and small shape differences remain. Each image layer is 530 × 740 × 3, and each mask layer is 530 × 740.

01 / Gaussian and Laplacian stacks

The Gaussian stack has six blur levels: σ = 0, 2, 4, 8, 16, 32 pixels. G0 is the original. To go from one level to the next, I use an extra blur of σ = √(σ target² − σ previous²). This works because Gaussian variances add. The finite filters only approximate the target scales. I make normalized OpenCV Gaussian vectors with radius ceil(4σ extra), apply them along x and y, and reflect the borders.

Li = Gi − Gi+1, i = 0,…,4
L5 = G5
I = L0 + L1 + … + L5

I never shrink or enlarge the layers and do not call a built-in pyramid function. Each Laplacian layer is the difference between two blur levels and can contain negative values. The final layer keeps the remaining broad shapes and colors. Without it, the layers cannot add back to the original.

In the detail layers, gray means zero. At each level, apple, orange and oraple use the same display scale. Different levels use different scales so their details are visible. The last layer uses normal RGB display. I use the raw float64 values for reconstruction, not the clipped PNGs.

Stack implementation
def gaussian_stack(image, sigmas=IMAGE_SIGMAS):
    """Successively blur without resizing; sigmas are nominal cumulative scales.

    Incremental sigma = sqrt(target**2 - previous**2), following Gaussian
    variance addition. Finite sampled kernels approximate this scale schedule.
    """
    current = np.asarray(image, dtype=np.float64)
    sigmas = np.asarray(sigmas, dtype=np.float64)
    if current.ndim not in (2, 3) or not current.size or not np.isfinite(current).all():
        raise ValueError('Expected a nonempty finite grayscale or RGB image.')
    if current.ndim == 3 and current.shape[2] != 3:
        raise ValueError('Color images require three RGB channels.')
    if sigmas.ndim != 1 or len(sigmas) < 2 or not np.isfinite(sigmas).all() or sigmas[0] < 0 or (np.diff(sigmas) <= 0).any():
        raise ValueError('At least two nonnegative, strictly increasing scales are required.')
    levels = []
    previous = 0.
    for target in sigmas:
        incremental = float(np.sqrt(target ** 2 - previous ** 2))
        if incremental > 0:
            radius = int(np.ceil(4 * incremental))
            weights = cv2.getGaussianKernel(2 * radius + 1, incremental, cv2.CV_64F).ravel()
            current = convolve1d(convolve1d(current, weights, axis=0, mode='reflect'), weights, axis=1, mode='reflect')
        else:
            current = current.copy()
        levels.append(current)
        previous = target
    return np.stack(levels)

def laplacian_stack(gaussian):
    """Adjacent Gaussian differences, with the final coarse residual retained."""
    gaussian = np.asarray(gaussian, dtype=np.float64)
    if gaussian.ndim not in (3, 4) or len(gaussian) < 2 or not np.isfinite(gaussian).all():
        raise ValueError('Expected a finite full-resolution Gaussian stack.')
    return np.concatenate((gaussian[:-1] - gaussian[1:], gaussian[-1:]), axis=0)

02 / A different transition width at each scale

The starting mask is white (1) on the left and black (0) on the right. I blur it at σ = 1, 2, 4, 8, 16, 32. Even the finest mask has a small blur of σ = 1; coarser masks have wider transitions. I limit tiny rounding errors to 0–1 and set the orange weight to exactly one minus the apple weight.

Ai = MiLapple,i
Bi = (1 − Mi)Lorange,i
Ci = Ai + Bi   ·   Oraple = Σ Ci

Each RGB channel uses the same mask weights. The two weights already add to one, so I do not divide by two again. All layers have the same size, so I reconstruct the image by adding them directly.

Mask-weighted reconstruction
def blend_stacks(left_laplacian, right_laplacian, masks):
    left_laplacian = np.asarray(left_laplacian, dtype=np.float64)
    right_laplacian = np.asarray(right_laplacian, dtype=np.float64)
    masks = np.asarray(masks, dtype=np.float64)
    if left_laplacian.ndim not in (3, 4) or left_laplacian.shape != right_laplacian.shape:
        raise ValueError('Both Laplacian stacks must have the same shape.')
    if masks.shape != left_laplacian.shape[:3] or not np.isfinite(masks).all():
        raise ValueError('One finite 2D mask is required per stack level.')
    if not np.isfinite(left_laplacian).all() or not np.isfinite(right_laplacian).all():
        raise ValueError('Image stacks must be finite.')
    if masks.min() < -1e-12 or masks.max() > 1 + 1e-12:
        raise ValueError('Mask weights must lie in [0,1].')
    # Clamp only floating-point roundoff in mask weights, never image bands.
    masks = np.clip(masks, 0., 1.)
    weights = masks[..., None] if left_laplacian.ndim == 4 else masks
    left_bands = weights * left_laplacian
    right_bands = (1 - weights) * right_laplacian
    bands = left_bands + right_bands
    return {'left_bands': left_bands, 'right_bands': right_bands, 'bands': bands,
            'left': left_bands.sum(axis=0), 'right': right_bands.sum(axis=0), 'image': bands.sum(axis=0)}

What changes at the seam?

The finest Laplacian layer shows grain and small edge details. Middle layers show fruit outlines and texture. Coarse layers show broad shading and color. Gaussian layers get blurrier but stay the same size. The hard cut has a clear vertical seam. Feathering softens it but mixes fine texture over the same wide area. The stack blend keeps a narrower change for detail and a wider change for color. It still has a visible change near the stem and center because the shapes and colors differ. I leave the source grain and small printed label unchanged. The result follows the textbook layout using stacks, so it is not an exact copy of the textbook image.

What I learned

I learned that the layers separate fine detail from broad colors and still add back to the original. A good blend needs the final broad layer and different mask widths for different levels. A small reconstruction error confirms the calculation, but does not mean the seam is invisible. The gray areas in the signed-band pictures mean zero, which helped me read the masked layers. I also learned to add the raw layers before clipping them for display.
