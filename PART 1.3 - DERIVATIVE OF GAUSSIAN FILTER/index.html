01 / Constructing the filters

I use the same unresized 512 × 512 grayscale cameraman input as Part 1.2, normalized to float64 [0, 1]. For σ = 2, the Gaussian radius is ceil(3σ), giving a 13 × 13 finite support. OpenCV creates a normalized one-dimensional Gaussian column and its outer product produces the two-dimensional kernel.

g = cv2.getGaussianKernel(2 * ceil(3 * sigma) + 1, sigma, cv2.CV_64F)
G = g @ g.T
Kx = scipy.signal.convolve2d(G, [[1., -1.]], mode="full")
Ky = scipy.signal.convolve2d(G, [[1.], [-1.]], mode="full")

Here DoG means derivative of Gaussian. The finite-difference kernels are the same as in Part 1.2. Full kernel convolution preserves every coefficient; the resulting x/y kernels have one additional column/row. Using a cropped kernel here would discard support and change the result. The Gaussian coefficients sum to 1.0000000000000002; the x/y DoG sums are -1.735e-18 and 0.000e+00, so constant intensities have essentially zero derivative.

Kernel images use nearest-neighbor enlargement so every coefficient remains visible. Gaussian brightness is normalized by its maximum. The two DoG kernels share a signed display scale: middle gray is zero, lighter positive and darker negative.

02 / Two steps or one convolution?

Both routes use SciPy convolution with same-size output and symmetric boundary extension. Route A first produces a blurred image and then differentiates it. Route B applies one precomputed DoG kernel directly to the input for each direction.

Filter implementation
def gaussian_kernel(sigma):
    if not np.isfinite(sigma) or sigma <= 0:
        raise ValueError('Sigma must be finite and positive.')
    radius = int(np.ceil(3 * sigma))
    column = cv2.getGaussianKernel(2 * radius + 1, sigma, cv2.CV_64F)
    return column @ column.T

def dog_kernels(sigma):
    gaussian = gaussian_kernel(sigma)
    # Full convolution retains the complete derivative support and alignment.
    return (gaussian, convolve2d(gaussian, DX, mode='full'),
            convolve2d(gaussian, DY, mode='full'))

def filter_routes(image, sigma):
    image = np.asarray(image, dtype=np.float64)
    if image.ndim != 2 or not image.size or not np.isfinite(image).all():
        raise ValueError('Expected a nonempty finite 2D image.')
    gaussian, kx, ky = dog_kernels(sigma)
    blurred = convolve2d(image, gaussian, mode='same', boundary='symm')
    sequential_x = convolve2d(blurred, DX, mode='same', boundary='symm')
    sequential_y = convolve2d(blurred, DY, mode='same', boundary='symm')
    direct_x = convolve2d(image, kx, mode='same', boundary='symm')
    direct_y = convolve2d(image, ky, mode='same', boundary='symm')
    return {'gaussian': gaussian, 'kx': kx, 'ky': ky, 'blurred': blurred,
            'sequential_x': sequential_x, 'sequential_y': sequential_y,
            'direct_x': direct_x, 'direct_y': direct_y,
            'margin': gaussian.shape[0] // 2 + 1}

I selected sigma = 2 and T = 0.04. Gaussian smoothing suppresses the dense grass responses seen with raw finite differences and produces smoother, wider responses around the photographer and tripod. At T = 0.02, the edge map retains more facial and background detail but also has thicker contours and additional clutter. 04 / Bells & Whistles: gradient orientation

Mandatory extension · No built-in angle functions

I compute the direction of the gradient vector, which is perpendicular to an edge contour and points toward increasing brightness. Because image coordinates have x to the right and y downward, angles increase clockwise: 0° is right, 90° down, 180° left and 270° up. Reversing edge polarity rotates the direction by 180°.

First set r = min(|Ix|, |Iy|) / max(|Ix|, |Iy|). This limits r to [0, 1]. For r > √2 − 1, use z = (r − 1)/(r + 1) and add π/4 after evaluating the series; otherwise z = r. This keeps |z| ≤ √2 − 1 and makes the alternating series converge rapidly:

a(z) = z − z³/3 + z⁵/5 − …   (24 terms)

The next omitted term bounds the truncation error by |z|49/49, below 4 × 10−21 over this reduced interval; actual accuracy is limited by floating-point rounding. I recover the first-quadrant direction using π/2 − a when |Iy| > |Ix|, then recover all four quadrants from the signs of Ix and Iy. Axis-aligned vectors work without division by zero. A zero vector receives a stored angle of zero and is displayed black because its magnitude is zero; its direction has no geometric meaning.

H = θ / (2π)   ·   S = 1   ·   V = clip(M / 0.15, 0, 1)

I implement HSV-to-RGB with six hue sectors using NumPy. Both images use the same brightness scale, so smoothing-related strength changes remain visible. Weak gradients become dark rather than producing prominent arbitrary colors in flat areas. This section uses no inverse trigonometric, complex-angle, OpenCV phase or Cartesian-to-polar angle function.

Manual direction calculation
def manual_orientation(dx, dy):
    """Direction in [0, 2pi), clockwise from +x in image coordinates.

    Compute arctangent with a 24-term alternating series after reducing its
    argument to abs(z) <= sqrt(2)-1. No built-in inverse trig or angle API.
    Zero gradients receive direction zero; their displayed value is black.
    """
    dx, dy = np.broadcast_arrays(np.asarray(dx, dtype=np.float64),
                                 np.asarray(dy, dtype=np.float64))
    if not np.isfinite(dx).all() or not np.isfinite(dy).all():
        raise ValueError('Gradients must be finite.')
    ax, ay = np.abs(dx), np.abs(dy)
    largest = np.maximum(ax, ay)
    ratio = np.divide(np.minimum(ax, ay), largest, out=np.zeros_like(largest), where=largest > 0)
    reduce = ratio > np.sqrt(2.) - 1.
    z = np.where(reduce, (ratio - 1.) / (ratio + 1.), ratio)
    power = z.copy()
    series = np.zeros_like(z)
    for n in range(24):
        series += power / (2 * n + 1)
        power *= -z * z
    alpha = series + np.where(reduce, np.pi / 4, 0.)
    alpha = np.where(ay > ax, np.pi / 2 - alpha, alpha)
    angle = np.where(dx < 0, np.pi - alpha, alpha)
    angle = np.where(dy < 0, 2 * np.pi - angle, angle)
    return np.where(largest > 0, angle % (2 * np.pi), 0.)

What I learned

Smoothing changes both noise sensitivity and the strength and width of edge responses, so it also changes the useful threshold. Composing the Gaussian and difference kernels gives the same interior gradient with a single image convolution, but cropping and boundary extension must be accounted for. HSV adds direction information that a magnitude-only edge map discards.
